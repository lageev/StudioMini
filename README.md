# Studio Mini

原生 macOS 上的 Android 构建精简版：打开项目、构建 APK、安装到设备。

## 下载

最新正式包见 [Releases](https://github.com/lageev/StudioMini/releases/latest)。

也可以使用 Homebrew 安装：

```bash
brew install --cask lageev/tap/studio-mini
```

解压 `Studio-Mini-*.zip`，把 `Studio Mini.app` 拖到「应用程序」。需要 macOS 14 或更高版本。本仓库只提供已签名公证的安装包和 Sparkle 更新源。

应用内「关于 Studio Mini」或应用菜单可以检查更新。
